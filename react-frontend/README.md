# React js Frontend


This is a React js frontend with vite. We are using bun as runtime and as package manager. Bun is the fastest javascript runtime which outperforms node and provides better development experience. It is a lightweight, ultra-fast javascript runtime which comes with multiple built-in features like testing,
bundler, package manager, built in sqlite support, and more. Checkout the docs for more details.

**Install dependencies:**

```bash
bun i
```

**Run the app:**

```bash
bun dev
```

First make sure that the backend is running in the '../hono-backend' folder. Checkout the main `README.md` for docs on how to run the complete application with database setup.
